# Odin Recipes

## About The Project
This project is part of **The Odin Project** foundations course. The goal is to build a basic recipe website using HTML to practice structuring web pages, linking multiple pages together, and working with Git and GitHub.

## Skills Demonstrated
* Writing semantic HTML elements (headings, paragraphs, lists, and links).
* Organizing project file structures.
* Managing version control using Git and GitHub workflows.
